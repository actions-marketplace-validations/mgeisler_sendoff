# Changelog

## Version 0.0.1 (2026-11-22)

Initial bootstrap release of `sendoff`:

- Added `sendoff changelog extract` to extract release notes for a
  version from `CHANGELOG.md` or `README.md`.
- Added `sendoff changelog update` to insert or update a version
  section in `CHANGELOG.md` or `README.md`.
- Added root `action.yml` composite action scaffold for GitHub
  Actions.
